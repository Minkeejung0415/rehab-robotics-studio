| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-3-06 | Spoofing | ContextMenu portal | accept | Single-user local mock UI; menu is not a privilege boundary |
| T-3-03 | Elevation of Privilege (UX) | Menu Delete / Select All + Delete | accept | Immediate delete, no modal (parity with keyboard); undo is v2 |
| T-3-07 | Tampering | Menu item dispatch | mitigate | Actions call typed store methods with known targetId from select-before-open; no eval/HTML injection in labels (static UI-SPEC strings) |
