| Token | Value | Usage |
|-------|-------|-------|

| sm | 8px | Compact element spacing; menu item vertical padding pair with horizontal |
| md | 16px | Default element spacing; properties section breathing room |

| Exception | Value | Why |

## Typography

Exactly 4 sizes, 2 weights:

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Label | 10px | 400 | 1.2 | Menu shortcuts (if shown), mono meta, badges |
| Body | 12px | 400 | 1.5 | Context menu item labels; properties body; param labels |
| Heading | 13px | 700 | 1.2 | Properties name field resting style; section titles |
| Display | 11px | 700 | 1.2 | Panel headings (`PROPERTIES`); menu section headers if needed |

**Weights allowed:** 400 (regular) and 700 (bold) only. Do not introduce 500/600 for new Phase 3 UI.

**Rename field:** Same visual as `.param-field input` — 12px / 400, full-width, monospace optional for value text only if matching kv-grid strong; prefer sans 12px for editable name to match inputs.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Duplicate |
| Empty state heading | (none — reuse existing panel empty) |

| Error state | Name cannot be empty — previous name restored. (silent revert on blur is OK; if visible toast/inline, use this exact sentence under the Name field) |

### Context menu item labels (exact)

| Target | Items (top → bottom) |
|--------|----------------------|
| Block | `Duplicate` · `Rename` · separator · `Delete` |

### Rename field label

- Label text: `Name` (param-field pattern)
- Replaces static `<h2>{node.name}</h2>` in properties header section

### Duplicate naming

- New block display name: `{originalName} copy` (single space + literal `copy`)
- No toast required on duplicate success

## Interaction Contract

### Context menu shell

| Rule | Spec |
|------|------|
| Implementation | Hand-rolled `position: fixed`; no npm menu library |
| Open | Right-click (`contextmenu`); `preventDefault()` on target |
| Select-before-open | Right-click selects target first, then opens menu (CONTEXT) |
| Position | `top/left` = `clientY` / `clientX`; clamp so full menu stays inside viewport (min 4px inset) |
| Z-index | Above canvas blocks/wires; below any future modal (suggest `z-index: 1000`) |
| Width | `min-width: 160px`; intrinsic grow for labels |
| Radius | `0` (sharp LabVIEW corners) |
| Close | Escape · pointer down outside · any menu action |
| Focus | Prefer focus first item or menu container for Escape handling; do not trap focus beyond dismiss |

### Menu item interaction

| State | Visual |
|-------|--------|
| Default | `textHi` on secondary surface |
| Hover | Background `#1c2226` (`panel3`) |
| Focus-visible | Accent border or 2px left bar `#4a90d6` |
| Destructive default | Label `#ec5a5a` |
| Destructive hover | Background `#3a2020`, label `#ffd9d9` |
| Separator | 1px `#23292d`, vertical margin 4px |

### Block menu actions

| Action | Behavior |
|--------|----------|
| Duplicate | Copy type, name+` copy`, params, ports; new ID; no wires; offset +40,+40; auto-select copy; close menu |
| Rename | Select block; ensure properties panel shows that block; focus Name input (rAF or short timeout — implementer discretion); close menu |
| Delete | `removeNode` (and connected wires per existing store); close menu |

### Wire menu actions

| Action | Behavior |
|--------|----------|
| Delete | `removeEdge`; close menu |

### Canvas menu actions

| Action | Behavior |
|--------|----------|
| Select All | Fill `selectedIds` with all block IDs; all blocks show `.is-selected`; wires not selected; close menu |

### Selection model (visual)

| Event | Visual result |
|-------|---------------|
| Select All | Every block uses selected styling (`border` + outline accent) |
| Empty canvas left-click | Clear `selectedIds` / selection |
| Select a wire | Clear block multi-select; wire selected styling (existing) |
| Single block click | Single-select (replace multi-select) |
| Keyboard Delete with multi-select | Remove all selected blocks (Claude discretion — required for Select All usefulness) |

### Rename (properties)

| Rule | Spec |
|------|------|
| Control | Controlled text input, ParamField-like |
| Commit | Every keystroke → store (live update canvas `.block-name`) |
| Empty blur | Revert to previous non-empty name |
| Multi-select | Name field edits the primary/focused selected block only (prefer `selectedId` or first of `selectedIds`); if ambiguous, keep single-select rename path from context Rename |
