| xl | 32px | Layout gaps (not primary for this phase) |
| 2xl | 48px | Major section breaks (not primary for this phase) |

| Exception | Value | Why |

| Toast vertical padding | 8px | Compact LabVIEW banner |

## Typography

Exactly 4 sizes, 2 weights:

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Label | 10px | 400 | 1.2 | Status badges (`idle` / `running`); RUNTIME label |
| Body | 12px | 400 | 1.5 | Toolbar button labels (`● Rec`, `○ Rec`, Deploy Mock); toast message |
| Heading | 13px | 700 | 1.2 | Toolbar brand title only (unchanged) |
| Display | 11px | 700 | 1.2 | RUNTIME value pill; toast optional mono emphasis (prefer Body 12px mono for toast text) |

**Weights allowed:** 400 (regular) and 700 (bold) only. Do not introduce 500/600 for new Phase 4 UI.

**Toast text:** 12px / 400, monospace family (`colors.mono`) to match log-row industrial feel; color `textHi` (`#dfe6ea`).

## Interaction Contract

### Run / Stop → block status badges (RT-01)

| Runtime action | Badge result | RUNTIME pill |
|----------------|--------------|--------------|
| Run (from idle) | Every node `status = 'running'` | `RUNNING` / green |
| Run (from paused) | Re-assert every node `status = 'running'` | `RUNNING` / green |
| Pause | Badges stay `'running'` | `PAUSED` / warn amber |
| Stop | Every node `status = 'idle'` | `IDLE` |
| E-STOP | Every node `status = 'idle'` | `ESTOPPED` / fault |
| Reset | Every node `status = 'idle'` | clears blocked → idle path |

| Rule | Spec |
|------|------|
| Update path | Synchronous bulk setter on `graphStore`, called from runtime `run` / `stop` / `estop` / `reset` (via store method or `actions` bridge) |
| Visual | Existing `.status-badge` + `statusColor[status]` only — no new badge chrome, no progress %, no pulse animation required |
| Empty canvas | Bulk setter is no-op (zero nodes); no toast |

### Recording toggle (RT-02)

| Rule | Spec |
|------|------|
| Placement | Toolbar: after Stop, before the separator that precedes Validate (order: Run · Pause · Stop · **Rec** · sep · Validate · Deploy · …) |
| Labels | Off: `○ Rec`; On: `● Rec` |
| Behavior | Toggle `systemStore.setRecording(!current)`; strip Recording value `On`/`Off` and level `fault`/`idle` (existing) |
| Disabled | Same as Run/Deploy: `state === 'estopped' \|\| state === 'fault'` |
| Pressed chrome | When recording On: apply Rec active classes (fault-family colors above); when Off: default `.btn` |
| No confirm | Immediate toggle; no modal |

### Deploy toast (DEP-01)

| Rule | Spec |
|------|------|
| Trigger | Click Deploy Mock (when not blocked) |
| Side effects | Existing `addLog` **and** show toast |
| Implementation | Hand-rolled `position: fixed`; `createPortal(..., document.body)`; no npm toast library |
| Position | Top center: `top: 24px`; `left: 50%`; `transform: translateX(-50%)` |
| Z-index | Above context menu — `z-index: 1100` (menu is 1000) |
| Radius | `0` (sharp LabVIEW corners) |
| Border | `1px solid #30383d` |
| Background | `#1a1f23` (`panel2`) |
| Shadow | `0 8px 18px rgba(0, 0, 0, 0.25)` |
| Single instance | If toast visible and Deploy clicked again, replace message / restart 2500ms timer (no stack) |
| Dismiss | Auto after 2500ms; click anywhere on toast dismisses immediately |
| Escape | Optional: Escape dismisses toast if focused/visible (recommended; not required for RT/DEP acceptance) |
| Role | `role="status"` + `aria-live="polite"` |

### Out of scope (do not design)

- Real Jetson deploy / hardware push
- Animated wire data flow (VIS-01)
- Per-block progress percentages or warning/error badge simulation during run
- Tabbed workspace (Phase 5)
- New npm dependencies
