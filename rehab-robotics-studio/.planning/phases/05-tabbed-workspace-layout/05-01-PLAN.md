# Plan 05-01: Tab Strip + Workspace Switching

## Goal

Wire a `WorkspaceTab` state into `App.tsx` and add the tab strip UI. Switch workspace contents based on active tab. Add all required CSS.

## Tasks

### Task 1 — Add `WorkspaceTab` state to App.tsx

In `src/App.tsx`:
- Import `useState` from React
- Add `type WorkspaceTab = 'diagram' | 'panel'`
- Add `const [activeTab, setActiveTab] = useState<WorkspaceTab>('diagram')`
- Add tab strip markup between `<Toolbar />` and `<main>`
- Conditionally render diagram workspace vs front-panel workspace

**Tab strip markup:**
```tsx
<div className="tab-strip">
  <button
    className={`tab${activeTab === 'diagram' ? ' is-active' : ''}`}
    onClick={() => setActiveTab('diagram')}
  >
    Block Diagram
  </button>
  <button
    className={`tab${activeTab === 'panel' ? ' is-active' : ''}`}
    onClick={() => setActiveTab('panel')}
  >
    Front Panel
  </button>
</div>
```

**Conditional workspace:**
```tsx
{activeTab === 'diagram' ? (
  <main className="workspace">
    <BlockLibrary />
    <GraphCanvas />
    <PropertiesPanel />
  </main>
) : (
  <main className="workspace workspace--front-panel">
    <Dashboard />
  </main>
)}
```
