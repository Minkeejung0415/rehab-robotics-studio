- Native input messages are `sensor_msgs.msg.Imu`.
- ROS orientation fields are populated as `.x`, `.y`, `.z`, `.w`; the device payload begins scalar-first but the ROS message boundary is standard `(x, y, z, w)`.
- Default native topics are `/esp32/{node_id}/imu`, producing `/esp32/master/imu` and `/esp32/slave/imu`.

Contract created by this plan for Plan 15-02:
- `ros_xyzw_to_opensim_rotation(x, y, z, w)` returns an immutable normalized rotation value in one documented convention or raises `ValueError` with a reason safe for status output.
- `VisualizerAdapter.update_sensor(sensor_id, frame_name, rotation)` updates only the named sensor triad.
- `VisualizerAdapter.status()` returns visualization availability/state/reason without requiring OpenSim-specific objects in callers.
- `create_visualizer_adapter(model_path, frame_mappings)` never makes module import depend on installed OpenSim bindings.
</interfaces>

| Boundary | Description |
|----------|-------------|
| ROS quaternion to conversion core | Untrusted numeric sensor fields enter rotation math. |
| Launch model path to filesystem/OpenSim | Operator-supplied path selects a model asset and optional native runtime. |
| Adapter to native visualizer | Python values cross into mutable native OpenSim/Simbody state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-01 | Tampering | Quaternion conversion | mitigate | Reject non-finite and near-zero values, normalize finite inputs once, and cover golden rotations. |
| T-15-02 | Denial of Service | Optional OpenSim import/model load | mitigate | Catch import/load/frame/visualizer failures and return an unavailable adapter while leaving the ROS layer able to run. |
| T-15-03 | Spoofing | Frame mapping | mitigate | Resolve only exact configured model-frame names and surface unknown mappings; never silently substitute another frame. |
| T-15-SC | Tampering | Package supply chain | accept | This plan installs no npm, pip, or cargo packages; OpenSim remains an optional pre-existing runtime. |
</threat_model>
