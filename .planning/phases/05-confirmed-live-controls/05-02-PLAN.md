# Plan 05-02: Build Confirmed IMU Block Controls

## Objective

Present the complete live configuration surface inside the ESP32 IMU Pair block and connect it to the confirmed ROS control contract.

## Tasks

1. Generalize rosbridge service/parameter calls into typed hardware-control requests with a uniform result shape.
2. Replace the isolated rate widget with a compact IMU configuration section for rate, filter, accelerometer range, gyroscope range, and effective sensor rate.
3. Maintain pending/draft/confirmed UI states; prevent node dragging while using fields and preserve the existing graph parameter model.
4. Add UI tests for acknowledgement-only updates, rejected values, and independent recording behavior.

## Verification

- `npm run build` passes.
- Component tests prove a confirmed response updates the graph/runtime state, while a rejected response does not.
- Manual browser test changes each control and observes its pending/confirmed/error state.
