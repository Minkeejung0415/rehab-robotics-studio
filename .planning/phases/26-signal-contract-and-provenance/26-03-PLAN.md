<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| verified firmware control response → fleet session | Device-originated capability/sensitivity declarations become canonical facts only after identity-bound parsing |
| route expectations/calibration file → verified declaration | Deployment assertions and calibration provenance are compared against device facts, never promoted as capability |
| mapping topic → applied cache | Mutable ROS JSON attempts to become authoritative provenance |
| decoded stream → per-MAC publisher | Device bytes become browser-visible JSON |

| T-26-12 | Tampering | decoded sample/config | mitigate | Validate finite/range/domain through the pure builder before nesting the envelope. |
| T-26-13 | Tampering / Repudiation | mapping-current callback | mitigate | Parse only bounded `applied_*` fields; signature and epoch ignore draft changes. |
| T-26-14 | Denial of Service / Injection | mapping labels/log detail | mitigate | Bound strings and log allowlisted reason codes only. |

| T-26-SC | Tampering | package installs | mitigate | No packages are installed. |
