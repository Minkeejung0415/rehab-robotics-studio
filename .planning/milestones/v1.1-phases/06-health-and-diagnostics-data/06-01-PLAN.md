# Plan 06-01: Passive Paired Health Snapshots

Publish stable JSON health snapshots for each ESP bridge and a combined pair
snapshot from the master. Derive stream timing and reconnect state locally, and
parse recording replies already received by the control path. Do not poll the
firmware status command over USB because that transport pauses the binary stream.

Verification: compile, unit-test health parsing/snapshot helpers, inspect all
three ROS status topics while both USB-connected ESPs are streaming.
