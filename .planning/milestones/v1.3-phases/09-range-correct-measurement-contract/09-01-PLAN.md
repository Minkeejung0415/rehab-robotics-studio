<objective>
Build the pure backend measurement-contract seam and integrate it into the bridge
node and filter pipeline. Tests created here prove DATA-01 (correct per-range SI
conversion) and DATA-02 (complete metadata on every published frame) at the
Python layer using only stdlib tools.

Purpose: The current bridge uses fixed ±2 g/±250 dps constants everywhere.
This plan replaces those with a single canonical contract module that both the
raw JSON envelope and native Imu publication derive from, preventing the scaling
error that makes a 4096-count sample report 2.45 m/s² instead of 9.81 m/s²
when the active range is ±8 g.

- measurement_contract.py: shared tables, immutable config, conversion helpers
- measurement_contract_cases.json: shared fixture consumed by Python and TypeScript
- test_measurement_contract.py: 09-01-01, 09-01-02, 09-01-03 coverage
- esp32_bridge_node.py: nullable confirmed fields, handshake confirmation,
  sensor_config in every raw frame, SI from config

- test_esp32_controls.py: confirmed-range-retention cases (09-01-03)
