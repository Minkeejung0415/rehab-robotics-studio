# Stabilize paired ESP32 joint-angle signal with still calibration and low-pass filtering

## Goal

Make the live pair-derived knee angle stable while the two ESP32 IMUs are held still, without hiding intentional movement.

## Approach

1. Keep deriving the relative inclination from the two real ROS ESP32 streams.
2. Collect a short, quiet startup window as the resting reference.
3. Subtract that reference and apply a time-aware low-pass filter before the graph executor receives the frame.
4. Reset estimator state when acquisition starts or stops, build the app, and exercise the live GUI with Playwright.

## Must Haves

- Both master and slave raw ROS messages remain required for the relative measurement.
- The paired angle is zero-referenced after a stable startup sample window.
- A stationary pair produces a visibly steadier joint-angle trace while deliberate movement still changes the display.
- The production frontend build passes and the live rosbridge GUI accepts both ESP topics.
